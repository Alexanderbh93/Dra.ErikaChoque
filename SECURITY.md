## Cómo Reportar una Vulnerabilidad

Si descubres una posible vulnerabilidad o fallo de seguridad, por favor **no abras un issue público** en GitHub.

Para reportarla de forma segura y responsable:

1. **Vía GitHub Security Advisories (Recomendado):** Ve a la pestaña **Security** del repositorio > **Advisories** > **New draft advisory** para reportarlo de forma privada.
2. **Vía Correo Electrónico:** Envía un correo con los detalles técnicos a: `alexanderbonillaherrera@gmail.com` con el asunto: `[Seguridad] Reporte de Vulnerabilidad - Dra. Erika Choque`.

### ¿Qué incluir en tu reporte?
* Descripción clara del problema identificado.
* Pasos para reproducirlo o prueba de concepto (PoC).
* Impacto potencial estimado.

### Tiempos de respuesta
* **Confirmación inicial:** Responderemos dentro de las primeras 48 a 72 horas laborales.
* **Seguimiento:** Te mantendremos informado sobre el estado de la corrección antes de publicar cualquier cambio.
